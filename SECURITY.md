# Security policy

Please do not report security issues in public issues.

Use GitHub's private vulnerability reporting instead: **Security → Report a vulnerability** on
<https://github.com/dangoquidev/Oracle>. You will get an answer as soon as possible.

Never paste a Discord token, a Leaguepedia Bot Password or a `.env` file in an issue or a pull request. If one leaked,
revoke it right away (Discord Developer Portal, Special:BotPasswords on Leaguepedia).
